# embedded-review

对STM32嵌入式项目进行全面综合审查，生成详细的审查报告。

## 功能说明

该skill对STM32嵌入式项目进行多维度深度审查，包括：

### 审查维度

1. **代码质量审查**
   - 命名规范一致性
   - 代码结构和可维护性
   - 注释完整性
   - 错误处理机制

2. **FreeRTOS任务管理**
   - 任务优先级配置
   - 栈大小合理性
   - 任务同步机制（互斥量、信号量、队列）
   - 死锁和优先级反转风险
   - 任务调度时序分析

3. **中断处理**
   - 中断优先级配置
   - 中断服务程序实现
   - 中断安全性（API调用、数据访问）

4. **内存管理**
   - 静态/动态内存分配
   - DMA缓冲区对齐
   - 栈溢出风险检测
   - 内存泄漏风险

5. **外设配置**
   - GPIO配置合理性
   - 时钟树配置
   - DMA配置
   - 外设初始化顺序

6. **安全性问题**
   - 缓冲区溢出风险
   - 数组边界检查
   - 并发安全（竞态条件、重入问题）
   - 敏感信息处理（密码、密钥）
   - 输入验证

7. **性能优化**
   - CPU效率分析
   - 内存使用优化
   - 功耗管理
   - 算法效率

8. **硬件相关**
   - 时钟配置验证
   - 通信协议实现
   - 电气特性考虑

## 使用方法

```
/embedded-review
```

执行后，skill将自动：

1. 分析项目结构，识别关键文件
2. 读取并分析以下内容：
   - 主程序文件（main.c, freertos.c等）
   - 外设驱动代码
   - 配置文件（.ioc文件）
   - 中间件集成代码
   - 头文件配置
3. 从多个维度进行深度审查
4. 生成详细的Markdown格式审查报告

## 输出报告格式

审查报告包含以下章节：

- **项目概览**：项目基本信息、MCU型号、主要组件
- **审查摘要**：审查文件数量、问题总数、严重程度分布
- **详细审查结果**：按维度分类的问题列表和改进建议
- **关键发现**：高优先级和需要立即修复的问题
- **改进建议**：短期改进和长期优化建议
- **附录**：审查文件列表、参考资料

## 审查重点

该skill特别关注STM32嵌入式开发中的常见问题：

- FreeRTOS任务配置和调度问题
- 中断与任务的资源竞争
- DMA配置和缓冲区安全
- HAL库返回值检查
- 硬编码敏感信息（WiFi密码、加密密钥等）
- 状态机实现的复杂度和正确性
- 串口/SPI等通信协议的鲁棒性
- 内存对齐和缓存一致性

## 适用项目

- 基于STM32 HAL库的项目
- 使用FreeRTOS的项目
- 集成LVGL、USB、网络等中间件的项目
- 通过STM32CubeMX生成的项目

## 注意事项

- 审查基于静态代码分析，部分问题需要结合运行时测试验证
- 生成的建议需要根据实际应用场景评估
- 性能相关建议需要实测数据支撑

## 示例输出

```markdown
# STM32项目审查报告

## 项目概览
- **项目名称**: STM32L4_TEST
- **MCU型号**: STM32L475VET6
- **主要组件**: FreeRTOS, LVGL, USB CDC, WiFi(ESP8266)

## 审查摘要
- 审查文件数量: 15
- 发现问题总数: 23
- 严重程度分布: 🔴 高 3 | 🟡 中 12 | 🟢 低 8

### 关键发现
1. 安全问题: WiFi密码硬编码在源代码中 (esp8266_wifi.c:45)
2. 风险: 状态机缺少超时处理可能导致死锁 (esp8266_wifi.c:212)
3. 建议: 任务栈大小可能不足，建议增大 (freertos.c)
```
